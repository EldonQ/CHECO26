# Static-layer rebuild, 6 November 2026

> **Historical (pre-replacement).** This record describes the 6 November 2026 rebuild of the 21,110-layer tree (bioclim = cnclim1km, 166.9 GB). On 2026-11-13 the bioclim theme was replaced with CHELSA v2.1 (1,210 layers, CC0-1.0); the database now holds 21,788 layers (183.1 GB) and the 532 cnclim1km layers were archived. The counts below are historical.

## What happened

The 773 static-theme layers of CHECO26 (bioclim, soil, topo, vege, hydro, dist and
the SMOD urban fraction) were still the bytes written before the pipeline was fully
ported to R. They were rebuilt with the released R pipeline and replaced, together
with 42 dependent layers that derive from them (soil profiles, vegetation focal
layers, topographic derivatives). 814 layers in total.

boundaries.

## Why values differ

The previous archive was built with GDAL 3.10.3; the released R pipeline uses
3.10.1. Re-projection therefore differs by small, unbiased amounts. Categorical
layers resampled by mode agree to 99.99%.

## Two defects found and fixed

1. `hydro90m_vars.scale_cm_exception: {slope_elv_dw_cel: 0.01}` was applied by the R
   port although the Python pipeline never read that key. The source is in metres
   (China-wide median 9.47), so the entry would have shrunk the layer 100×. The key
   has been removed from `pipeline_r/config.yaml`.
2. `channel_elv_up_cel` has a source of 42,440 × 73,827 cells (~12.5 GB), which
   `terra::project()` cannot hold in memory. It was rebuilt with block-wise sentinel
   masking and a streaming `gdalwarp` call.

## Consequences for the archive

- `MANIFEST.csv` re-hashed: 21,110 layers, 166.94 GB (168.49 GB including the
  auxiliary masks and species files).
- `provenance_table.csv`: `actual_range` refreshed for the 814 replaced layers, and the
  3,422 rows that stored only six significant digits were recomputed, so every row now
  matches the delivered file to the last digit.
- All checkers pass: docs consistency 18/0, trends 39/0, Table 1 17/17,
  independent verification 16/0, cross-source numbers agree.
